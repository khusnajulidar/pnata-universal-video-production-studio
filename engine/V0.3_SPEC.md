# Production Engine v0.3 — Specification

**Status:** Milestone A complete and verified; Milestone B layout primitives implemented, local/CI verification pending; Milestones C–E not implemented  
**Target branch:** `feat/production-engine-v0.1.0`  
**Baseline:** v0.1 still renderer and v0.2 animated 2D renderer  
**Compatibility rule:** v0.1 and v0.2 projects and commands remain supported; v0.3 is a new explicit path.

## 1. Purpose
v0.3 incrementally adds dependable typography/image layout, timeline/captions, reviewed audio composition, and technical QC without claiming to be a full nonlinear editor or universal renderer.

## 2. Non-negotiable P'Nata policy
- No music, without exception.
- Allowed audio only: speech/narration, genuinely non-musical sound effects, genuinely non-musical natural/environmental ambience, or silence.
- Reject unclassified, unreviewed, music, and embedded audio.
- No complete depictions of humans or animals, including silhouettes or fragments arranged to imply a complete figure.
- No figurative depiction of Allah, prophets, angels, or unseen matters.
- Human review declarations are attestations, not machine certification. If a policy status is missing or ambiguous, stop.

## 3. Milestone A — schema and validation (complete)
JSON Schema 2020-12 and strict Python validation cover required policy declarations, asset provenance and rights/review declarations, safe project-relative paths, scene/layer references and timing, keyframes, and reviewed allowed audio metadata. Local verification on the user's Windows/Python 3.11 environment passed 21 tests; the validation fixture passed; CI run 45899621794 succeeded. These declarations do not constitute automated semantic review.

## 4. Milestone B — typography and image layout (implemented; verification pending)
New module: `pnata_engine.layout_v3`.
- Text wrapping across whitespace and explicit paragraphs.
- Horizontal left/center/right and vertical top/middle/bottom alignment.
- Line spacing and inner padding.
- Explicit overflow: `error` (fail), `clip` (return visible lines and mark clipped), and `shrink_to_fit` (reduce only to required min_font_size, otherwise fail).
- Font path fallback in caller-supplied order, then Pillow default font.
- Image `contain`, `cover`, and explicit `stretch`; cover uses deterministic normalized crop anchors.
- Drawing helper for measured text layouts.
- Tests added in `tests/test_layout_v3.py`.

Important boundaries: this milestone supplies layout primitives, not yet a full v0.3 renderer integration. Font fallback does not guarantee glyph coverage or complex-script shaping; callers should use suitable reviewed fonts. The default Pillow font may not render all scripts. Clip is deliberately explicit and reports clipped status. Human visual review remains required.

## 5. Remaining milestones
### C — Timeline and captions
Layer visibility windows, timed caption support, safe margins, and deterministic timing while preserving scene sequencing.

### D — Reviewed audio
Explicit narration/SFX/natural ambience track handling, trim/offset/gain/fades, deterministic mixing, silence support, and strict rejection tests. No music generation, composition, recommendation, or playback.

### E — QC and release gate
FFprobe stream/duration/FPS/dimensions/codec checks; audio metrics only where reliable; machine-readable report; full regression; human visual/audio review and delivery package.

## 6. Compatibility and status discipline
Keep v0.1 and v0.2 commands and fixtures intact. v0.3 features must not be described as tested until local and CI execution succeeds. Keep development on `feat/production-engine-v0.1.0`; do not merge to `main` without explicit authorization.
