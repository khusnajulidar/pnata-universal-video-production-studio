# Acceptance Test Checklist — v0.1

- [ ] Motion graphics explainer: storyboard, graphics, voiceover/SFX yang sah, MP4, source, QC.
- [ ] Cinematic visual essay: tidak memaksa gaya motion graphics; hanya visual yang sesuai aturan.
- [ ] Educational: urutan penjelasan, keterbacaan, demonstrasi objek, akurasi.
- [ ] Documentary/factual: sumber klaim dan lisensi arsip terverifikasi.
- [ ] Promotional: klaim produk/testimoni tidak palsu; hak logo/aset jelas.
- [ ] Audio violation: file musik ditolak untuk penggunaan; alternatif voiceover/SFX/ambience/silence.
- [ ] Visual violation: referensi figur manusia/hewan utuh tidak disalin; alternatif non-figuratif dibuat.
- [ ] Missing capabilities: jika TTS/FFmpeg tidak tersedia, tidak mengklaim MP4 final.
- [ ] Continuity: aset dan keputusan final dipertahankan; tidak mengulang pekerjaan selesai.
- [ ] Delivery: MP4/source/aset/README/QC hanya dinyatakan ada jika benar-benar tersedia.
