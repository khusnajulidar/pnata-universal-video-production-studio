# Motion Graphics / Kinetic Typography Profile

## Purpose and fit
Explain, compare, persuade, or clarify through designed movement, typography, diagrams, data, shapes, and spatial composition.

## Design system
Define grid, margins, safe areas, type scale, font roles, line lengths, colour tokens, shape language, icon rules, stroke weights, corner logic, and contrast before animation. Maintain a coherent system while allowing intentional variation.

## Motion system
Specify object properties over time: position, scale, rotation, opacity, path, easing, duration, overlap, anchors, and z-order. Use anticipation, action, settle, and follow-through where appropriate. Establish a vocabulary such as reveal, compare, connect, emphasize, and transform. Avoid gratuitous bounce, particles, and motion on every element. Synchronize to spoken meaning, never to a musical beat.

## Information design
One dominant message per frame/beat. Reveal complex diagrams progressively while preserving spatial memory. Label units, sources, scales, and comparisons. Never distort charts for drama. Test text at target device size.

## QC
Typography legible at native size and after compression; motion hierarchy clear; diagrams accurate; no clipping, overlap, jitter, unsafe margins, or inconsistent easing; every animated element has a communication purpose.
