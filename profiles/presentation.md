# Presentation / Narrated Slides Profile

## Purpose and fit
Support a speaker or narrated explanation with structured visual information.

## Design
One message per slide. Use consistent grid and hierarchy. Prefer diagrams and evidence to paragraphs. Keep type large enough for the display environment. Use progressive disclosure only when it clarifies.

## Narrative and evidence
Structure context → question → argument/sections → evidence/examples → synthesis → action or discussion. Label axes, units, dates, denominators, and sources. Do not crop chart axes or omit context. Place citations close to claims or on a readable source slide.

## Audio and QC
Narration matches slide timing; dense information has reading time; speech is clear; no music; charts are honest; slides are readable and not overcrowded.
