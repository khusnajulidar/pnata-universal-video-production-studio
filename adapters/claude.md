# Claude Adapter

- Pasang skill sesuai mekanisme yang didukung lingkungan Claude yang digunakan.
- Pastikan SKILL.md dan folder referensi ikut terbaca.
- Jangan menganggap render, TTS, image generation, atau video generation tersedia hanya karena skill menyebutkannya.
- Periksa akses file, shell, FFmpeg, Python, Node, browser, dan koneksi tool/MCP yang tersedia.
- Jika shell dan FFmpeg tersedia, gunakan pipeline render teruji dan simpan source serta hasil di folder proyek.
- Jika MP4 tidak dapat dibuat, serahkan artefak yang benar-benar tersedia dengan status DRAFT, bukan FINAL.
- Patuhi larangan musik dan figur manusia/hewan utuh walaupun referensi atau tool eksternal menawarkan aset tersebut.
