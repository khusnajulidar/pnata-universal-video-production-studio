# ChatGPT Adapter

- Terapkan core melalui skill/instruksi proyek yang tersedia di lingkungan ChatGPT.
- Gunakan file tools untuk mencari dan membaca file proyek; jangan mengasumsikan file lama tersedia di direktori kerja.
- Gunakan image generation hanya untuk aset gambar yang memang diperlukan dan tetap patuhi aturan visual P'Nata.
- Gunakan tool video/TTS hanya jika tersedia dan terkonfirmasi pada sesi tersebut.
- Jika container/Python/FFmpeg tersedia, periksa kemampuan aktual sebelum render; verifikasi file ekspor.
- Jangan mengklaim ChatGPT dapat menjalankan semua tahap bila tool tidak tersedia.
- Untuk file hasil, gunakan jalur unduhan yang benar-benar dibuat dan diverifikasi pada sesi aktif.
- Jangan memublikasikan atau mengirim ke layanan eksternal tanpa persetujuan pengguna.
