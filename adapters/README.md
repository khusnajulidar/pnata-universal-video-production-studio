# Agent Adapters

P'Nata memiliki satu core universal. Adapter menerjemahkan prinsip core ke kemampuan runtime masing-masing. Adapter tidak memberikan kemampuan baru kepada platform.

Sebelum produksi, lakukan discovery terhadap tool aktual dan tandai AVAILABLE / CONDITIONAL / UNAVAILABLE / NOT TESTED. Bila adapter spesifik tidak tersedia, ikuti SKILL.md dan jelaskan batas runtime.
